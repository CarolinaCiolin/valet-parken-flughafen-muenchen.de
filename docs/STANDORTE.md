# Standorte und Dachmarke

| Projekt | Rolle | Profil | Stand |
| --- | --- | --- | --- |
| valet-parken-flughafen-muenchen.de | einzelner Flughafen, Valet-Affiliateportal | munich | bestehende Website, Quelle der bisherigen freigegebenen Inhalte |
| valet-parken-flughafen-frankfurt.de | zukünftiger Flughafenstandort | frankfurt | technische Profilvorlage; Inhalte/Anbieter/Links/Branding noch separat vorzubereiten |
| valet-parkservice.com | zukünftige Dachmarke | umbrella | technische Profilvorlage für mehrere Flughäfen; Standortseiten je relevantem Flughafen und eigenes Booking geplant; spätere Partner-SaaS-Option, noch keine Implementierung |

Die Dachmarke erhält nicht automatisch einen einzigen Flughafen als Einsatzgebiet. Die Profil-Wortmarken für Frankfurt/Dachmarke sind konfigurierbare Startwerte, keine abgeschlossene Markenentwicklung. „Flughafen auswählen“ verweist im Dachmarkenprofil auf #flughaefen; dafür muss im redaktionellen Seitenaufbau ein echter Flughafenbereich mit diesem Anker angelegt werden. Flughafenprofile verwenden #anbieter.

Standortdaten und redaktionelle Daten pro WordPress-Installation getrennt halten. Eine Profilumschaltung schreibt bestehende Inhalte nicht um. Nicht das Münchner Live-System auf Frankfurt umstellen, um eine zweite Website zu bauen; neue WordPress-Installation mit demselben Theme/Anbieterplugin verwenden.

Öffentliche technische Quelle: https://github.com/CarolinaCiolin/valet-parken-flughafen-muenchen.de . Vorerst kein zusätzliches Repository erforderlich. Ein späteres neutrales Core-Repository kann mit Erhalt der Update-Slugs getrennt werden.

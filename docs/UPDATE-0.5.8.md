# Update 0.5.8 – helles VPM-Website-Icon

Neues Icon: VPM in Dunkelblau auf hellem Cremeweiß mit kurzem Goldakzent. Die bisherige dunkle VP-Kachel wird in den gebündelten Icon-Dateien ersetzt. Keine Änderung am Header-Logo oder an der Banner-Reparatur aus 0.5.7.

## Für die bestehende Website: kein ZIP-Update erforderlich

1. zwischenstand/website-icon/vpm-website-icon-512.png über GitHub als Originaldatei herunterladen.
2. WordPress → Einstellungen → Allgemein → Website-Icon → Bild auswählen/ändern.
3. Neue PNG auswählen und speichern. Das native WordPress-Icon gilt für Deutsch und Englisch und hat Vorrang vor dem Theme-Fallback.

Alternativ kann die Auswahl je nach WordPress-Oberfläche unter Design → Customizer → Website-Informationen erscheinen. Die 512-Pixel-Datei verwenden, nicht den Screenshot oder die kleinen Favicon-Versionen. Browser können das alte Icon noch eine Zeit lang anzeigen.

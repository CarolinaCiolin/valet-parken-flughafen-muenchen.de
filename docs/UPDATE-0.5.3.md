# Update 0.5.3 – Deutscher Affiliate-Hinweis im Footer

Der deutsche Footer zeigt jetzt auch bei fehlendem, leerem oder nur mit Leerzeichen gefülltem Customizer-Feld einen Affiliate-Hinweis:

„Einige Links auf dieser Website sind Affiliate-Links. Wenn Sie darüber buchen, können wir vom Buchungspartner eine Provision erhalten. Für Sie erhöht sich der Buchungspreis dadurch nicht.“

Ein vorhandener eigener deutscher Hinweis bleibt erhalten. Der englische Hinweis bleibt englisch. Footer-Links, Gestaltung und Inhalte werden nicht geändert; es werden keine englischen Rechtstexte erzeugt.

Nur vpm-hybrid.zip als Theme-Ersatz hochladen, danach LiteSpeed Cache leeren. Kein Inhaltsimport, keine Plugin-Aktualisierung erforderlich. Alle bisherigen Theme-Änderungen einschließlich Breadcrumb-Markup ohne sichtbare Breadcrumbs bleiben enthalten.

Lokale Prüfung: leeres, fehlendes und nur aus Leerzeichen bestehendes Feld; eigener Hinweis bleibt erhalten; lokalisierte Hinweise und veröffentlichte Rechtslinks bei 1440 und 390 Pixeln. Keine Installation auf Hostinger durch dieses Update.

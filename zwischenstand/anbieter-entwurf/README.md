- [Mobil: alle sechs Karten](mobil.png)

Eigenständige Designvorschau mit bestehenden Anbietertexten und Buchungslinks aus der bisherigen Offline-Vorschau. Kein WordPress-Update und keine Veröffentlichung auf Hostinger. Die Illustrationen sind symbolische Grafiken, keine tatsächlichen Standortabbildungen. Der gemeinsame Bildbogen wird nur für diesen Entwurf per CSS aufgeteilt; für die spätere Umsetzung sind einzelne optimierte Bilddateien vorgesehen.

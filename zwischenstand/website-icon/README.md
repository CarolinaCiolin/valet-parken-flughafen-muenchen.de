# Helles VPM-Website-Icon

![VPM-Icon](vpm-website-icon-512.png)

**Für WordPress:** [vpm-website-icon-512.png](vpm-website-icon-512.png) öffnen und die Originaldatei herunterladen (Download raw file).

Unter Einstellungen → Allgemein → Website-Icon die neue PNG auswählen und speichern. Gilt für Deutsch und Englisch. Dafür ist kein Theme-/Plugin-Update nötig.

Kleine Fassungen zur Kontrolle: [64 Pixel](vpm-favicon-64.png), [32 Pixel](vpm-favicon-32.png), [16 Pixel](vpm-favicon-16.png).
